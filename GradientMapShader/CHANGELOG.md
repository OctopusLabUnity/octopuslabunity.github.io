# Changelog

## 1.0.0

Initial release.

- Four URP shaders: Basic, Water, Sprite and Skybox.
- Basic shader with Light, View, Depth and Flat shade types.
- Alpha, Normal, Darken and Lighten maps.
- Fill, Rim, Specular and Outline effects.
- Custom Inspector with a Rich Gradient field. Rich Gradient is included.
- `SetGradient` runtime API.
- Grayscale Image tool.
- Supports Unity 2022.3 or newer with URP 14 or newer, in Linear and Gamma color space.
