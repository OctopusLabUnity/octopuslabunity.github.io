2.4. Luminance

Default Rec.601 weights work for most albedo. Override with _LuminanceWeights for artistic control — see Strength.

2.5. Strength

Zero keeps the original albedo; one fully replaces it. Animate for transitions into Stylize looks.

3.1. Properties

Property Description

_GradientMap 1D gradient lookup texture

public static void ApplyMap(Material mat, Texture2D map, float strength)

5.1. Troubleshooting

Pink materials usually mean a missing shader — reimport from the Asset Store.

  • Map looks banding: increase bake resolution
  • Colors inverted: flip the gradient direction
  • No change visible: confirm Strength is above zero
  • Washed out: check sRGB on the LUT
